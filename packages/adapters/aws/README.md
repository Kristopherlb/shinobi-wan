# @shinobi/adapter-aws

AWS adapter: lowers backend-neutral intents and platform nodes to Pulumi AWS resources (59 lowerers), generates resource plans, and deploys via the Pulumi Automation API. Depends only on @shinobi/contracts and @shinobi/ir.

Part of the [Shinobi V3 monorepo](../../../README.md) — see the repo root for architecture, invariants, and development commands.
